Mini Inventory Management System

A small inventory management dashboard built with React, TypeScript, and CSS as a hands-on programming learning project.

The goal of this project is to strengthen my understanding of TypeScript, React components, functions, interfaces, props, state management, and frontend development by building something practical.

Learning Objectives

- Understand TypeScript interfaces and type annotations.
- Work with arrays, objects, and functions.
- Build reusable React components.
- Understand component props and data flow.
- Practise CSS Grid and responsive layouts.
- Learn React state management.
- Implement basic inventory operations.

Tech Stack

- React
- TypeScript
- Vite
- CSS

Current Features

- [x] Product data structure and TypeScript interfaces

Getting Started

Clone the repository:

git clone YOUR_REPOSITORY_URL

Navigate into the project:

cd mini-inventory

Install dependencies:

npm install

Start the development server:

npm run dev
